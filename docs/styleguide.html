LWVNC Style Guide

Every colour and component in styles.css. Copy the markup from this file instead of writing inline styles.

Colours

Official LWV brand palette (lwv.org/brand-standards). Use the token name, e.g. var(--lwv-purple), never a raw hex value. Gold is for rules, brackets and dark backgrounds; gold text on white is too faint to read.

--lwv-purple
#820263 · buttons, links, accents

--lwv-purple-dark
#521C50 · headings, dark bands

--lwv-blue
#005596 · voting info, secondary

--lwv-red
#be0f34 · urgent notices only

--lwv-gold
#eca400 · brackets, rules, on dark

--ink
#1d1a22 · strong text

--body
#3d3a42 · paragraphs

--muted
#5c5862 · captions, labels

--surface
#f7f5f8 · light sections

--lwv-purple-tint
#f6ebf3 · hover/active wash

Eyebrow labels

Small uppercase label above a heading. .eyebrow runs a hairline to the right; .eyebrow--center puts short rules on both sides; .eyebrow--plain has none.
